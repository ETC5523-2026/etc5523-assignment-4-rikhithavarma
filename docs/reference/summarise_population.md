# Summarise Population Growth

Calculate population changes between two selected years for Australian
states and territories.

## Usage

``` r
summarise_population(data, start_year, end_year)
```

## Arguments

- data:

  A data frame containing year, state and population.

- start_year:

  The starting year for comparison.

- end_year:

  The ending year for comparison.

## Value

A data frame containing the starting population, ending population,
absolute change and percentage growth.
