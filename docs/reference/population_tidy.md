# Australian State and Territory Population Data

Population estimates are taken from the Australian Bureau of Statistics
(ABS). The dataset contains June population estimates for each year.

## Usage

``` r
data(population_tidy)
```

## Format

A data frame with 128 rows and 3 variables:

- year:

  Year of the population estimate (2010-2025).

- state:

  State or territory abbreviation.

- population:

  Estimated resident population in persons.

## Source

Australian Bureau of Statistics (ABS), National, state and territory
population, Table 4: Estimated Resident Population, States and
Territories.
<https://www.abs.gov.au/statistics/people/population/national-state-and-territory-population>

## Details

Annual estimated resident population for Australia's eight states and
territories from 2010 to 2025.
